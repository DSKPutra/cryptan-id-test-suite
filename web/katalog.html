Panjang kunci / kombinasi

Deteksi berjalan di browser (Pyodide) memakai kode Python yang sama dengan CLI. Berkas teks/kode: .txt .md .csv .json .yaml .html .c .h .py .java .go .rs .js .ts. Untuk PDF/DOCX/XLSX gunakan CLI atau GUI Streamlit.

Browser hanya dapat membaca halaman yang mengizinkan CORS. Untuk halaman lain (mis. CSRC NIST, PDF sertifikat CMVP) gunakan CLI: python -m algo_catalog select --url <URL> — CLI menghormati robots.txt.
