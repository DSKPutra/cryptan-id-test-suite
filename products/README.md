# Produk uji UK-3

- `latihan/` — berkas produk latihan **asli** dari materi UK-3 (`securefile.py`, `securefile_v11.py`, `run_log.py`,
  `rng_lab.py`, `run_tests.py`). Tidak dipublikasikan (di-*gitignore*); salin dari folder materi bila tersedia.
- `replika/` — **REPLIKA** yang dibuat dari spesifikasi prompt UK-3. Dipakai otomatis bila `latihan/` kosong.
  Hash-nya berbeda dari slide.
- `ruang_lingkup.yaml` — ruang lingkup, batasan, dan izin tertulis. Aplikasi UK-3 hanya menguji produk yang tercantum.
